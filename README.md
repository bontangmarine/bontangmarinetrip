# Bontang Marine Trip

Website resmi untuk informasi dan pemesanan perjalanan laut / wisata Bontang Marine.

## 🚀 Fitur Utama
- Informasi paket trip & kapal
- Galeri destinasi wisata
- Form pemesanan via WhatsApp

## 🛠️ Teknologi yang Digunakan
- HTML5 & CSS3
- JavaScript
- GitHub Pages (Deployment)
